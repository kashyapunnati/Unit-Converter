# Unit Converter

---

## 📌 Description

The Unit Converter is a simple web application that converts values between different length and weight units.

Users can enter a value, select the source unit and target unit, and get the converted result instantly.

---

## 🎯 Objective

The main objective of this task is to practice:

- JavaScript functions
- Conditional logic
- Form and input handling
- DOM manipulation
- Unit conversion calculations
- Responsive web design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- JavaScript DOM
- Math and conversion formulas

---

## ✨ Features

- Enter a numeric value
- Select units using dropdown menus
- Convert length units
- Convert weight units
- Live conversion while typing
- Convert button for manual conversion
- Results rounded to 2 decimal places
- Validation for invalid values
- Prevents conversion between different unit categories
- Responsive design for mobile and desktop

---

## 📏 Supported Length Units

- Meter (m)
- Kilometer (km)
- Feet (ft)
- Mile (mi)

---

## ⚖️ Supported Weight Units

- Kilogram (kg)
- Gram (g)
- Pound (lb)
- Ounce (oz)
